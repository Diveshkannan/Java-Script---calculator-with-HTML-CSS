# JavaScript Calculator

## Overview

This project is a simple calculator built using **HTML, CSS, and JavaScript** as part of my web development learning journey. It performs the four basic arithmetic operations through an interactive graphical interface while validating user input and handling common edge cases such as division by zero.

The primary goal of this project was to strengthen my understanding of JavaScript functions, DOM manipulation, event handling, conditional logic, and responsive user interface design by building the application completely on my own.

---

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Input validation before calculations
* Division by zero handling
* Interactive user interface
* Responsive button interactions
* Custom-designed layout using CSS

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

---

## How It Works

1. Enter the first number.
2. Enter the second number.
3. Select the desired arithmetic operation.
4. The calculator instantly displays the selected operation and its result.
5. A Finish button displays a thank-you message after use.
